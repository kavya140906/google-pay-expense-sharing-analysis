# Google Pay Expense Sharing Analysis

## Overview

This project focuses on analyzing expense-sharing data to understand shared expenses and spending patterns using Python.

## Objectives

* Organize and analyze expense-sharing information.
* Understand expense distribution among participants.
* Present insights that support expense tracking and analysis.

## Technologies Used

* Python
* Pandas 

## Project Files

* `sharing_app.py` – Python source code.
* `sharing_app2.pdf` – Project report.

## How to Run

1. Install Python on your system.
2. Install the required libraries used in the project.
3. Run the Python file:
   `python sharing_app.py`
